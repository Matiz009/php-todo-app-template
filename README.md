## Tech stack

PHP (mysqli), MySQL, Bootstrap, jQuery

## Getting started

1. Install a local PHP and MySQL server, such as XAMPP.
2. Create a database called `crud` with a `tasks` table.
3. The connection is set in `db.php` (`localhost`, user `root`, empty password).
4. Put the folder in your web root and open `http://localhost/php-todo-app-template/`.

## Project structure

```
index.php  Page and task list
db.php     Database connection
```
